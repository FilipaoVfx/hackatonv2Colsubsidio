## ADR-004
Base de datos: Supabase PostgreSQL.

Arquitectura Event-Driven.

## ADR-006
Observer como mecanismo de comunicación.

## ADR-007

## ADR-008
State para ciclo de vida de llamadas.

## ADR-009
Strategy para narrativas.

## ADR-010
Adapter para Vapi, ElevenLabs, OpenAI y Supabase.

## ADR-011
Repository para persistencia.

## ADR-012
Mission Control como interfaz principal.

## Principios
Event First • Explainability • Realtime • Low Coupling • Provider Agnostic.
