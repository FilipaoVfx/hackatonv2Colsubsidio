# Prima

La prima es el valor que pagas periódicamente (en estos planes, cada mes) por tu seguro.

# Cobertura

La cobertura es el conjunto de situaciones que el seguro protege. Cada producto tiene coberturas distintas; el asesor entrega el detalle completo (clausulado) al formalizar.

# Beneficiario

La persona o personas que reciben el respaldo económico del seguro cuando ocurre el evento cubierto. Tú eliges a tus beneficiarios al formalizar.

# Caja de compensación

Entidad como Colsubsidio que administra beneficios sociales (subsidios, recreación, vivienda, protección) para trabajadores afiliados y sus familias.

# Póliza

El contrato del seguro. Solo existe cuando el asesor la formaliza contigo; este chat prepara tu perfil y recomendación, no emite pólizas.
